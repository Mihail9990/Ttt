# 0.3.2-preliminary: предварительная native-панель

Это не выпуск для реального счёта. Native UI и протокол прошли статические проверки; Android device/network fault и end-to-end проверки ещё обязательны. Не подключать к реальному счёту. Текущий контракт: NATIVE_STATE_CONTRACT.md. Описание симуляционного прототипа ниже историческое.

# MT5 RECOVERY overlay 0.2.0 — прототип симуляции

**Это не готовый бот реальной торговли.** Старые функции ручной установки TP/SL убраны из панели. Новая панель работает только с `/api/recovery/*` сервера в режиме `simulation`, `live_trading:false`. На реальный счёт не подключать. APK предыдущей версии в родительской папке не содержит этих изменений.

## Жесты и размер

- Свернутый значок: `>` слева, `<` справа, `⌃` снизу. Нажатие или свайп внутрь экрана открывает панель.
- Удерживайте свёрнутый значок до вибрации, затем перетаскивайте. После отпускания он закрепляется к ближайшему левому, правому или нижнему краю. Верхний край не используется.
- Слева открывается слева направо, справа справа налево, снизу снизу вверх. Обратный свайп **по заголовку** сворачивает; контент свободно прокручивается.
- Положение и сторона сохраняются после перезапуска. При повороте экрана координаты ограничиваются доступной областью.
- В настройках ширина 35–95%, высота 25–90%, масштаб текста и значка 75–150%. В панели есть быстрые кнопки масштаба `−`/`+`. Поля цен сохраняются при сворачивании, открывании и изменении размера, но не после остановки приложения.
- Для перемещения не требуются Accessibility или чтение экрана Bybit. Только обычное разрешение overlay.

## Демо-интерфейс

Две независимые дистанции: «Исходный SL от цены входа» и «Повторный триггер от SL поддержки», обе по умолчанию 0.70. Исходный SL не может быть меньше 0.60 (0.60 разрешено); для повторного триггера остаётся отдельное требование положительного значения. Старая настройка SL ниже 0.60 не исправляется молча: подтверждение новых диапазонов отклоняется с подсказкой. Применяются вместе с подтверждением новых диапазонов, не изменяют активные ордера отдельно. В состоянии показаны фактические настройки сервера. При наличии открытых позиций подтверждение замены диапазонов отключено.

Выбор 1/2 диапазонов. Для каждого вводятся точная цена первичного триггера, BUY/SELL и объём. Команды отправляются после нажатия «Подтвердить диапазоны (демо)». Кнопка отмены диапазонов доступна только если сервер разрешил `can_cancel_ranges`. Закрытие позиции и отмена её диапазона показаны, но **пока отключены**: симуляционный backend не имеет подтверждённого результата закрытия позиции.

Показаны диапазоны, отдельные убытки, позиции, ордера и история. Список последних трёх категорий пока технический JSON, не завершённый дизайн. Пока панель открыта, состояние обновляется раз в 5 секунд. Введённые цены при обновлении не перезаписываются. При неизвестном результате команды повторной автоматической отправки нет. До отправки команда проверяет simulation-состояние сервера; реальная торговля в этом прототипе заблокирована.

Сервис запускается без соединения, чтобы можно было проверить жесты. До подтверждённого соединения торговые демо-кнопки отключены.

## Соединение

В настройках HTTPS origin без пути, например `https://your-host.example`; Bearer token не короче 32 символов (совпадает с WIDGET_TOKEN сервера). Ключ шифруется Android Keystore. Нужен действующий сертификат, небезопасный обход HTTPS отсутствует. Настройку сервера и сертификата этот исходник не выполняет. После изменения подключения лучше остановить и повторно включить панель.

## Сборка и проверки

Android Studio / JDK 17+, Android SDK 35. `./gradlew assembleDebug lintDebug` (Windows `gradlew.bat`). Готовый путь: `app/build/outputs/apk/debug/app-debug.apk`.

Проверки этой ревизии: 593 проверки pure Java геометрии/жестов + 639 проверок размеров + 30 проверок независимых дистанций. Исходники проверяются ECJ по Android 15 API; это не Gradle/DEX/APK сборка. Android SDK в текущем окружении отсутствует; APK 0.2 пока не собран. На Android-устройстве и сервере не выполнялись UI/end-to-end проверки. Нужны проверки перетаскивания, трёх краёв, поворота, клавиатуры, системной навигации, повторного открытия и восстановления сервиса на устройстве (Samsung A22 / Android 12).

Не запускается автоматически после перезагрузки. Отдельные приложения/система могут запрещать overlay. Никаких реальных ордеров при разработке и проверке не отправлялось.

### Проверка ограничения минимального SL

42 pure-Java проверки дистанций прошли, включая 0.60, ввод с запятой и отклонение 0.59999999. Все Android Java-исходники проходят ECJ-компиляцию по Android API. APK этой правки не собран: wrapper не смог получить Gradle 8.9 (`Network is unreachable`). На телефоне правка не проверялась.

# MT5 Side Panel — Android 0.1.0 (исходники)

Нативная боковая панель поверх Bybit: ручка справа, свайп влево или нажатие открывает панель; свайп вправо по заголовку или нажатие сворачивает. Панель показывает все позиции MT5, выбранный тикет, сторону, объём, цену входа, действующие уровни и счёт. Доступно отдельное поле TP и SL, расстояния в единицах цены от входа, не терминальные points. Пустое поле сохраняет уровень, ноль запрещён. Автоматическое выставление на новые позиции отсутствует: только явная кнопка «Применить».

## Сборка

Открыть папку `android` в Android Studio с JDK 17+ и установленным Android SDK 35 / Build Tools. Нужен интернет для официальных Gradle/Google/Maven зависимостей. Gradle wrapper 8.9 включён.

Linux/macOS: `./gradlew assembleDebug`
Windows: `gradlew.bat assembleDebug`

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Это отладочная сборка, не релизный подписанный продукт. Для релиза создайте собственный ключ подписи в Android Studio; ключи в исходники не включать.

## Подключение

1. Сначала настройте VPS-сервис и проверяемый HTTPS-сертификат. Самоподписанные и просроченные сертификаты приложение не обходит.
2. В приложении введите HTTPS origin без `/api`, пути и query, например `https://your-host.example`. Ключ доступа сервиса не короче 32 символов; он шифруется AES-GCM с ключом Android Keystore. Резервное копирование приложения отключено. После изменения настроек остановите и включите панель.
3. Отдельно разрешите «Поверх других приложений» в настройках Android. Запустите панель кнопкой. Уведомление foreground-service позволяет остановить её; также есть кнопка остановки в основном экране.
4. Откройте Bybit. Панель использует MT5 API, не считывает и не управляет интерфейсом Bybit. Убедитесь, что на VPS выбран тот же счёт.
5. Выберите конкретный тикет, введите TP и/или SL и примените. Сообщение «подтверждено» появляется только при серверном статусе `verified`. При тайм-ауте автоматического повтора нет; обновите позиции и проверьте фактические уровни в MT5 прежде чем повторять.

## Контракт

`Authorization: Bearer <token>` для API. `GET /health` возвращает `mode` (`dry_run`/`live`). `GET /api/positions` возвращает `account` (число), `server`, массив `positions` с ticket, identifier, symbol, side BUY/SELL, volume, price_open, sl, tp. Для совместимости понимается также `account:{login,server}`.

`POST /api/positions/{ticket}/protection`: request_id UUID, expected_entry, expected_symbol, expected_side, expected_volume, expected_identifier и необязательные tp_distance/sl_distance. Незаданные поля не отправляются. Ответ status verified/rejected/unknown, message и необязательная position.

## Проверки и ограничения

Проверена компиляция Java-исходников компилятором Eclipse ECJ по API Android 15 (Robolectric android-all). Выполнены 9 проверок HTTPS-адреса. Это не Android Gradle/DEX/APK сборка и не запуск на устройстве. APK в этом окружении не собран: Android SDK отсутствует; на смартфоне не проверялись overlay, клавиатура, Android Keystore и foreground-service.

До реального использования требуется сборка, установка и проверка сначала с mock/dry_run. Не отправляйте реальные команды при проверке интерфейса. Система и отдельные приложения могут скрывать overlays; показ абсолютно везде не гарантируется. Автоматического старта после перезагрузки нет. Остановка панели не отменяет уже отправленную серверу команду и не меняет позиции.

## Настройка размера

В основном экране приложения есть «Размер панели»: отдельные ползунки ширины (35–95%) и высоты (25–90%) от доступного экрана. Изменения сохраняются на устройстве автоматически, применяются к открытой панели без её перезапуска и не очищают поля TP/SL. Кнопка «Стандартный размер» возвращает 85% / 75%. Открыть настройки можно нажатием на постоянное уведомление MT5.

Минимум для читаемости: ширина 240 dp, высота 260 dp; если экран меньше, размер ограничивается доступным экраном. Учитываются системные панели и вырезы на Android 11+, оставляется небольшой запас. При повороте телефона размер пересчитывается; содержимое можно прокручивать, а заголовок со свайпом закрытия остаётся на месте. Размеры не масштабируют шрифт или ручку открытия. Выполнены 639 проверок правил размеров; применение настроек на реальном Android ещё не проверено.

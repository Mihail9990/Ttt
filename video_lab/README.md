# MotionForge Studio 0.2.0

Рабочее пространство для создания видео из сгенерированных изображений на CPU.
В демонстрации рыжий котёнок идёт по лесной дорожке: меняются позы лап, положение
головы и хвоста, персонаж движется по сцене, под ним перемещается тень.

Изображения создаются доступным в ChatGPT генератором изображений. Локальный
движок строит промежуточные кадры, управляет траекторией, камерой и композицией,
экспортирует MP4 и GIF. Установленная нейросеть Depth Anything V2 Small INT8
оценивает глубину фона. Локальная диффузионная модель видео здесь не используется.

## Возможности

- До шести независимых дорожек объектов или персонажей.
- Атласы последовательных поз с прозрачностью, списки кадров и отдельные PNG/WebP.
- Согласованное масштабирование поз и выравнивание по линии опоры.
- Промежуточные кадры через двунаправленный оптический поток с учётом alpha.
- Траектория, размер, угол и прозрачность с ключевыми точками времени.
- Зацикливание анимации, настройка скорости смены поз и времени появления.
- Тень под объектом, плавающие пылинки, движение камеры с параллаксом.
- MP4/H.264, необязательная готовая звуковая дорожка, компактный GIF-просмотр.
- Вычисление по одному видеокадру; ограниченный кэш пар поз.
- Шаблоны новых проектов, воспроизводимые примеры и автоматические проверки.

## Структура

| Путь | Назначение |
| --- | --- |
| `studio.py` | Композиция, прозрачные позы, траектории, MP4/GIF |
| `motionforge.py` | Базовый движок, нейросеть глубины, камера и видеокодировщик |
| `assets/` | Сгенерированные фон и персонаж, описание происхождения и SHA-256 |
| `projects/` | Сценарии с параметрами времени и движения |
| `prompts/` | Точные запросы для создания исходных изображений |
| `models/` | Описание модели и лицензия; веса скачиваются командой setup |
| `cache/` | Повторно используемые карты глубины |
| `output/` | Готовое видео, GIF и отчёт |
| `WORKFLOW.md` | Порядок подготовки нового сюжета для ассистента |
| `tests/` | Проверки движения, прозрачности, длительности и экспорта |

Исходники и пример сцены находятся в отдельной папке `video_lab` и отдельной
ветке репозитория. Установка весов и результаты рендера не добавляются в Git.

## Запуск

Нужны Python 3.12 или новее и FFmpeg с libx264 в PATH. FFmpeg:
https://ffmpeg.org/download.html

Linux:

```bash
cd video_lab
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python studio.py doctor
.venv/bin/python studio.py setup
.venv/bin/python studio.py render projects/kitten_walk.json --output output/kitten_walk.mp4 --gif output/kitten_walk_preview.gif
```

Windows, PowerShell:

```powershell
cd video_lab
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe studio.py doctor
.venv\Scripts\python.exe studio.py setup
.venv\Scripts\python.exe studio.py render projects/kitten_walk.json --output output/kitten_walk.mp4 --gif output/kitten_walk_preview.gif
```

`setup` проверяет и при необходимости загружает закреплённую модель глубины,
27.3 МБ, с проверкой SHA-256. Модель и готовые изображения доступны локально
при последующих запусках; сборка видео после установки работает без внешнего API.
Для фона без оценки глубины можно указать `"depth": "flat"`.

`doctor` проверяет версию Python, OpenCV, ONNX Runtime, наличие FFmpeg и модели.
`--threads 2` уменьшает число потоков CPU. Стандартный результат — 1280×720,
24 кадра/с; поддерживается вертикальное видео 720×1280. Допустимы чётные размеры
до 2 073 600 пикселей, не более 1920 по каждой стороне.

## Новый сюжет

```bash
.venv/bin/python studio.py new-job jobs/new_film --brief "Котёнок замечает бабочку и делает несколько шагов к ней"
```

Команда создаёт папки, задание на изображения и шаблон `project.json`. После
этого ассистент создаёт изображения через встроенную генерацию ChatGPT, помещает
их в папку задания и запускает render. Сам Python-скрипт не вызывает скрытый
облачный генератор и не создаёт недостающие изображения автоматически.

Пример прозрачного персонажа использует сетку 4×4, 16 поз одного котёнка. Можно
использовать другой атлас или список последовательных изображений с одинаковым
ракурсом. Весь персонаж должен помещаться в каждую ячейку. Поля `columns`, `rows`,
`count` задают сетку; `pose_fps` — скорость смены опорных поз. Между ними движок
синтезирует кадры оптическим потоком. `interpolation` поддерживает `flow`, `blend`
и `nearest`.

В `keys` время задаётся в секундах. `x`, `y` — координаты точки опоры, доли ширины
и высоты кадра. `height` — высота рабочей рамки объекта относительно кадра.
`rotation` задаётся в градусах, `opacity` от 0 до 1. Пропущенные значения наследуются
из предыдущей точки. `ease: "smooth"` плавно ускоряет и замедляет участок, обычное
движение использует `linear`. Меньшая работающая рамка `work_size` ускоряет расчёт.

Готовый аудиофайл можно указать полем `audio` в проекте. По умолчанию ролик без звука.
Файлы проекта ссылаются на изображения относительно расположения JSON.

## Качество и пределы

Система делает движение на основе заранее созданных поз. Она не восстанавливает
точную 3D-модель персонажа и невидимые поверхности по одному фото. Хорошие,
последовательные опорные кадры сильно влияют на результат. Большие изменения
позы и перекрытия могут вызывать растяжения и двоение при интерполяции. Для сцен
с разными ракурсами лучше создавать отдельные планы и соединять готовые ролики.

Генерация изображений выполняется внешним инструментом ChatGPT; скорость
локального рендера не включает время создания этих изображений. Это рабочий
конвейер с проверенным примером, который можно расширять новыми сценами.

## Проверка

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Проверяется движение самого объекта при неподвижном фоне, промежуточное положение
в известном смещении, прозрачные края, точное количество кадров, длительность
переходов, декодирование MP4 и GIF, ограничение кэша, обработка ошибок, нейросеть
глубины и реальные сгенерированные позы. Результаты замера демонстрации записаны
в `BENCHMARK.json`.

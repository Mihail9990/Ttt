# Вид из окна поезда

Режим создаёт видео из связанных продолжений одного пейзажа. В готовой сцене
одна долина продолжается на соседнем изображении; камера движется вдоль
собранного пространства. Полноэкранного растворения между картинками нет.

Демонстрация `projects/train_mountains.json`: 84 секунды, 1280×720, 24 кадра/с.
Первые примерно 60 секунд — горная долина и озеро, затем горы постепенно
переходят в лесистую долину с рекой. Видео без текста и звуковой дорожки.

## Как получена непрерывность

1. Генератор изображений ChatGPT создал первый широкий участок горной долины.
2. Его правые 35% использованы как исходник для расширения вправо. Новый участок
   сохранил общую часть берега, склонов и неба, добавив следующий участок долины.
3. Правый край второго участка расширен таким же образом к хвойному лесу.
4. Движок сопоставил общие детали соседних изображений и поправил небольшой
   сдвиг, масштаб и наклон. В двух соединениях нашлись сотни подтверждённых
   совпадений; типичная ошибка совмещения около 1–1.5 пикселя.
5. Изображения соединены узким пространственным швом. Получилась одна панорама
   5060×720, по которой непрерывно перемещается окно камеры.

Таким образом, изображения меняются за границами окна, когда поезд проезжает
следующий участок. Соседние планы не накладываются целиком поверх друг друга.
Если у двух изображений нет надёжного общего участка, сборщик останавливается
с ошибкой; независимые открытки он не выдаёт за непрерывную местность.

## Запуск

После установки зависимостей из основного README:

```bash
.venv/bin/python train.py build projects/train_mountains.json
.venv/bin/python train.py render projects/train_mountains.json --output output/Train_Window_Mountains_84s.mp4
```

Для Windows используйте `.venv\Scripts\python.exe` вместо `.venv/bin/python`.
Готовая панорама уже включена в пример; build нужен для её пересборки.
Нейросеть глубины для этого режима не требуется.

## Настройки

| Поле | Значение |
| --- | --- |
| `sections` | Связанные участки по порядку, с общей областью на краях |
| `panorama` | Результат пространственной сборки |
| `seconds`, `fps` | Длительность и частота кадров |
| `camera_keys` | Время и нормированное положение вдоль маршрута от 0 до 1 |
| `window` | Неподвижная рамка окна и слабое отражение на стекле |
| `foreground` | Более быстрое движение ближней травы |

Путь камеры непрерывен по положению и скорости. В примере точка времени 60
секунд удерживает горный участок приблизительно на первую минуту, затем
движение продолжается к лесу. Для длинного ролика можно добавлять новые
продолжения и точки времени, а не многократно повторять весь пейзаж.

Ближний план использует травяную текстуру нижнего края той же панорамы с
ускоренным движением и небольшим смазыванием; только эта близкая текстура
циклически повторяется. Дальняя местность проходит один раз. Лёгкая вибрация
добавляет ощущение поезда. Рамку и ближний план можно отключить независимо.

Это панорамная анимация созданной местности. Она не является съёмкой реального
маршрута или полной реконструкцией 3D-мира. Исходные изображения создаются
встроенной генерацией ChatGPT, а совмещение, движение и видео считаются локально
на CPU, без локальной диффузионной модели видео.

## Новые маршруты

Сохраните удачный первый участок. При расширении передавайте его правые
30–40% как изображение-исходник, требуя сохранить его слева и достроить пространство
только справа с той же камерой, светом и линией горизонта. Сохраняйте точные
промпты и проверяйте общие детали перед длинным рендером. Для резкого изменения
ландшафта сначала создайте промежуточный географический переход.

Исходные запросы: `prompts/train/`. Изображения и хэши: `assets/train/manifest.json`.
Отчёт совмещения: `assets/train/route_panorama.registration.json`.
Измерения готового ролика: `TRAIN_BENCHMARK.json`.

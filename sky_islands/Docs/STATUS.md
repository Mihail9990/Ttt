# Состояние реализации

Это первый исходный срез Sky Islands на **Unreal Engine 5.6**. Репозиторий содержит настоящий C++-проект, переносимое игровое ядро, процедурный рельеф и цепочку подготовки ассетов. **Unreal Editor в среде разработки отсутствует. Компиляция UE-модуля, запуск сцены, импорт `.uasset`, установка на телефон и сборка APK не подтверждены.**

Сначала нужен [Editor build и bootstrap карты](BUILD.md). Файл `Content/Maps/SkyWorld.umap` создаётся движком; в исходниках нет подменяющего его пустого или выдуманного бинарного файла.

## Реализация и проверка

| Часть | Что написано | Что проверено и чего пока нет |

| Копание | Удаление объёма сферическими отпечатками, пересоздание меша, выбор лопаты/кирки по слою, выдача ресурсов только при новом удалённом объёме | Тесты SDF/триангуляции, повторного копания и конечных данных. Скорость готовки коллизий и игра на Android ещё не измерены |

| Управление и интерфейс | Персонаж от первого лица, выбор инструментов, рынок на Canvas HUD, сенсорные зоны движения/обзора и кнопки основных действий | Код UE не исполнялся. ## Переносимые тесты

Команды воспроизводятся без Unreal:

```bash
python sky_islands/Tools/validate_project.py
bash sky_islands/Tests/run_core_tests.sh
bash sky_islands/Tests/run_terrain_tests.sh
python -m unittest discover -s sky_islands/Tests -p 'test_build*.py'
```

В текущем запуске:

- Ядро: **2114 утверждений PASS** — добыча, детали, крепёж, escrow, уникальные дома, обмен, фабрики, ограниченная сериализация и сохранение ресурсов.
- Рельеф: **PASS**, тестовая сетка 10 816 треугольников, в том числе 88 треугольников внутренней полости; удалённый объём 33 777 800 см³ в тестовом сценарии.
- Build orchestration: **3 теста PASS** — ошибка компилятора останавливает pipeline; Python без маркера успеха не считается успешным; маркер без сохранённой карты не считается успешным.

Эти результаты не являются компиляцией адаптеров Unreal и не доказывают сетевую или мобильную работоспособность.

## Следующая проверяемая цель

Первый настоящий Editor build на установленном UE 5.6: устранить найденные UHT/C++/Python API ошибки, создать карту, импортировать ассеты, запустить Play и проверить добычу → покупку досок → установку деталей → крепёж → сохранение/загрузку. Затем проверить две локальные сетевые сессии и только после этого собирать и испытывать Android APK.

Летающие базы, корабли, бригады, перенос домов, масштабная общая карта, погода, пираты, охрана и дроны остаются согласованным направлением развития. Они не объявляются готовыми возможностями этого первого среза.

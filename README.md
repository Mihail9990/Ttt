# Android APK Builder

Тестовый Android-проект на Kotlin с автоматической сборкой APK в GitHub Actions.
Сборка выполняется в облаке GitHub, управление доступно через браузер Android.

## Как получить APK

1. Откройте вкладку **Actions** в этом репозитории.
2. Выберите **Build Android APK**.
3. Дождитесь завершения автоматической сборки после коммита либо нажмите **Run workflow**.
4. Откройте успешный запуск, внизу страницы найдите **Artifacts**.
5. Скачайте ZIP-артефакт, распакуйте его и установите `app-debug.apk` на телефон.

Первый APK — тестовое приложение «APK Starter» с кнопкой проверки.
После установки убедитесь, что оно запускается.

## Исходный код

- `app/src/main/java/com/example/apkstarter/MainActivity.kt` — экран и логика.
- `app/src/main/AndroidManifest.xml` — настройки приложения.
- `app/build.gradle.kts` — конфигурация Android.
- `.github/workflows/build-apk.yml` — процесс сборки.

**Важно:** Debug APK рассчитан на тестирование. GitHub runner может генерировать новую подпись при каждом запуске, поэтому для обновления без удаления приложения следует настроить постоянный ключ в GitHub Secrets. Не размещайте закрытые ключи в репозитории.

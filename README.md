# LEGION RUSH

Портретный офлайн-экшен для Android: ведите отряд одним пальцем, выбирайте ворота, отбивайте волны, побеждайте громил и усиливайте бойцов между забегами. Огонь ведётся автоматически.

## Как играть

- Проведите пальцем влево или вправо, чтобы направить отряд.
- Выбирайте ворота: они дают бойцов, урон, скорострельность или броню до конца забега.
- После определённого числа побед выберите одно из трёх усилений.
- Заработанные за забег монеты тратьте в разделе «Улучшения»: бонусы сохраняются на телефоне.
- Игра не требует интернета после установки. Сохранения хранятся на устройстве; удаление приложения удалит и прогресс.

## Сборка

Нужны Godot 4.5.2, Python 3 и NumPy. Исходные 3D-модели и текстуры загружаются из закреплённых версий с проверкой SHA-256; условия перечислены в [CREDITS.md](CREDITS.md).

```sh
python3 -m pip install numpy
python3 legion_game/tools/fetch_assets.py
godot --headless --path legion_game --editor --quit
godot --path legion_game
```

Для Android используется шаблон экспорта Godot 4.5.2, Android SDK и Java 17. GitHub Actions автоматически проверяет игру и прикладывает подписанный тестовый APK к результату сборки. Ключ в репозитории предназначен только для личных тестовых сборок, не для публикации приложения.

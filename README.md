# Небесные острова — Godot 4.6.3

Игра от первого лица с личным небесным островом, естественным объёмным грунтом, добычей ресурсов и свободным строительством. Основная реализация теперь находится в `sky_godot` и собирается в Android APK без Unreal Editor.

Это первая игровая версия. Художественный ориентир — реалистичный мир с подробными материалами. Текущая графика использует настоящие CC0 модели и PBR текстуры, но ещё не соответствует ранее обсуждённым кинематографическим концептам. Производительность на Samsung A22 пока не измерена.

## Играть и собрать

Откройте [sky_godot/project.godot](sky_godot/project.godot) в **Godot 4.6.3** после подготовки ассетов:

```bash
python -m pip install Pillow
python sky_godot/tools/prepare_assets.py
```

Нажмите F6/F5. На компьютере: WASD — ходить, мышь — смотреть, ЛКМ — инструмент, колесо или 1–7 — выбрать инструмент, E — взаимодействие, M — рынок. На телефоне есть сенсорные кнопки и управление жестами.

Для Android установите JDK 17, Android SDK (platform35/build-tools35.0.1) и официальные export templates Godot 4.6.3, затем:

```bash
python sky_godot/tools/build_android.py --java /path/to/jdk17 --sdk /path/to/android-sdk
```

Результат: `sky_godot/Artifacts/Sky-Islands-Godot.apk`. Скрипт проверяет реальные исходные ассеты, импортирует проект, выполняет игровые и сетевые тесты, экспортирует APK и проверяет подпись. Используется ключ для тестовой установки; это не публикация в Google Play.

## Состояние разработки

Работают изменение грунта с полостями, рубка и добыча, детали заданных размеров и углов, индивидуальные гвозди и саморезы, рынок, производственные рецепты, продажа соединённой постройки, базовая вооружённая охрана и сохранения. Есть сетевая сессия с авторитетным хостом; игроки подключаются по адресу хоста, UDP порт27777. Это прототип общей карты, ещё без учётных записей, постоянного публичного сервера и промышленной защиты от читов.

Расширенная строительная физика, профессиональные персонажи и анимации, строительные бригады, дирижабли, межсерверная экономика и полноценный большой мир требуют дальнейшей разработки. Подробности и подтверждённые проверки перечислены в STATUS.md.

Предыдущий исходный проект Unreal сохранён в `sky_islands` и ветке `sky-islands`. Старый `legion_game` — отдельный исторический проект.

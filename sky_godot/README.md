# Небесные острова — Godot

Играбельный ранний 3D-прототип на **Godot 4.6.3**: личный остров в общей карте, добыча ресурсов, свободное строительство, рынок и производство. Основной язык — GDScript; Android-сборка использует GL Compatibility и ARM64.

Цель художественного направления — реалистичные материалы и свет. Текущий прототип использует настоящие PBR-текстуры и отдельные детализированные модели, но ещё не достигает кинематографической графики согласованных концептов. Персонажи, заводы и часть предметов пока имеют упрощённое оформление. Производительность на Samsung Galaxy A22 и других телефонах ещё не измерена.

## Что можно попробовать

- Исследовать четыре объёмных небесных острова; копать землю и породу с изменением самой геометрии, рубить деревья и собирать конечные ресурсы.
- Ставить доски и кирпичи с выбранными размерами и поворотом. Молоток и шуруповёрт создают отдельные соединения с расходом гвоздей и саморезов; соединения можно разобрать.
- Покупать и выставлять ресурсы на рынок, приобретать лесопилку, кирпичную печь и плавильню, превращать сырьё в материалы и продавать постройки.
- Размещать охранника, турель или дрон на острове, использовать оружие и планер, управлять малым островом у штурвала.
- Сохранять мир и подключаться к хосту по IP через меню «Сеть». Это прототип прямого ENet-подключения, без публичного сервера и системы аккаунтов.

Масштаб карты, строительные размеры и число объектов ограничены защитными пределами прототипа. Полный замысел с крупной постоянной онлайн-картой, бригадами строителей и развитой логистикой остаётся дальнейшей разработкой; подробности — в [STATUS.md](docs/STATUS.md).

## Быстрый запуск

Установить официальный Godot 4.6.3 и Python 3.11 или новее. Из корня репозитория:

```bash
python3 -m pip install Pillow==11.3.0
python3 sky_godot/tools/prepare_assets.py
godot --headless --path sky_godot --editor --import
godot --path sky_godot
```

Подготовка ассетов скачивает модели и текстуры по закреплённым адресам и проверяет SHA-256. Папку `sky_godot` также можно импортировать в Godot Editor через `project.godot` после подготовки ассетов. Подробная сборка APK и проверки описаны в [BUILD.md](docs/BUILD.md).

## Управление

| Действие | Компьютер |
| --- | --- |
| Движение и обзор | WASD, мышь |
| Прыжок / планер | Space / F |
| Инструменты | 1–7 или колесо мыши |
| Применить инструмент / разобрать | Левая / правая кнопка мыши |
| Взаимодействовать, войти в управление островом | E |
| Рынок / строительство / меню | M / B / Esc |
| Сохранить | F5 или кнопка «Сохранить» |
| Поворот детали по трём осям | R / Q / C |
| Изменить длину / ширину / высоту | = и − / [ и ] / ; и ' |

На телефоне доступны сенсорная область движения слева, обзор справа, кнопки инструментов и действия. Размеры и углы деталей задаются в панели «Строить». Системная кнопка «Назад» открывает меню.

Для совместной игры один игрок выбирает «Открыть этот мир для подключения», остальные вводят его IP в меню «Сеть». Используется UDP-порт **27777**; устройства должны иметь сетевую доступность друг к другу. Автоматическое соединение через интернет и NAT не реализовано. Сохранение хоста хранится в Godot `user://sky_world_v2.json`; клиентские данные игры приходят от хоста.

## Устройство проекта

| Путь | Назначение |
| --- | --- |
| `scenes/main.tscn` | Стартовая сцена |
| `scripts/main.gd` | Мир, игровые действия, сеть и сохранения |
| `scripts/simulation.gd` | Ресурсы, экономика, владение и производство |
| `scripts/island.gd` | Объёмная земля и выкапываемые полости |
| `scripts/player.gd`, `scripts/hud.gd` | Игрок и сенсорный интерфейс |
| `scripts/art.gd` | Материалы, модели и освещение |
| `tools/prepare_assets.py` | Проверяемая подготовка исходных ассетов |
| `tools/build_android.py` | Импорт, тесты, экспорт APK и проверка подписи |
| `tests/` | Проверки симуляции, земли, игры и реальных сетевых процессов |

Происхождение моделей и текстур, лицензии и ограничения художественных материалов перечислены в [ASSETS.md](docs/ASSETS.md).

# Подпись APK: текущий тестовый режим и будущие релизы

## Сейчас

В этом репозитории используется автоматическая **тестовая подпись без GitHub Secrets**.

- Ключ уже находится в `signing/test-debug.jks`.
- Его пароль `android`, alias `androiddebugkey`.
- Workflow проверяет, что подписанный APK использует фиксированный сертификат.
- Никаких ручных действий не нужно: достаточно обновить код или нажать **Run workflow**.
- Последующие сборки с более высоким `versionCode` обновляют приложение поверх установленного, если подпись и идентификатор приложения не изменились.

**Переход:** установленный APK от предыдущего временного debug-ключа нужно удалить один раз. Удаление приложения стирает его локальные данные.

## Ограничение безопасности

Ключ специально хранится в репозитории с общедоступным паролем. Это удобно для личного тестирования, но **не является защищённой подписью разработчика**. Не используйте этот ключ для финансовых, коммерческих, публичных приложений или приложений пользователей.

Не делайте этот ключ рабочим производственным ключом. При переходе к публикации создайте отдельный уникальный release-key и храните его безопасно, например, в GitHub Actions Secrets. Для приложений, уже установленных с тестовым сертификатом, переход на другой сертификат обычно потребует переустановки и может привести к потере локальных данных.
